### Added

- `gomoveshift metrics collect` now records the Shorts arm decisions in `<seo storage>/shorts_arm_decisions.json` (`schema`, `decided_at`, one entry per arm) once every factor is decided; a run that fails part-way leaves the old `decided_at`. The `ARM_DECISION` lines are unchanged.
- `gomoveshift health check` rule 12, `seo_feedback_stale`, files an incident when the decisions file is missing, unreadable or over 36 h old (`seo_feedback_stale:decisions`), one grouped incident when settled YouTube Shorts posted in the last 28 days have null views or average view percentage (`seo_feedback_stale:metrics`), and one grouped incident for queued Shorts whose rewrite a read-only dry run of `queue sync-short-text` reports as `changed` but the nightly sync did not apply (`seo_feedback_stale:queued`; refused rows stay `short_text_sync_refused:<project>`, but an unusable sidecar or generator failure holds an open row). An open row's detail and count are refreshed without a second push. Each resolves when it clears; an unreadable input is a note and keeps its open incident live. See `docs/seo-feedback-stale.md`.
