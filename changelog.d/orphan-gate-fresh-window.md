### Fixed

- The orphan gate's fresh window now opens when the dead publish job ENDED (`result.ended_at`; `now` when the record has none), not when it started, so a catalog fetched mid-run no longer counts as fresh. Any dead state the backlog retries (failed, cancelled, stalled, killed) opens it through one shared rule (`launch.dead_publish_result`), the newest dead job wins, and a failed drive with no job record forces a refresh instead of accepting any stamped snapshot.
- A hand `health publish` refreshes the live catalog like the backlog tick; the tick builds one refresher and a failing fetch is tried once per tick, not once per failed drive; the refresh's summary lines go to stderr so `health backlog --json` stays valid JSON.
- A missing ledger now refuses with "missing or unreadable" and opens the deduped `orphan_upload` incident. A live video matching only a title another drive derives too (or an LF whose every form is shared) now refuses naming both drives instead of passing, unless it predates this drive's first publish attempt or a receipt names it. An open orphan row is no longer closed with a false "checkpoint no longer has this LF" when another drive starts sharing the title.
