### Fixed

- A drive whose bracket route names only a country or a state (a county-level or two-state label is unchanged) now titles each long-form with that label plus its own measured recording date, for example `Ireland (Sep 16, 2025)`, instead of the bare label every other same-country drive shares. The burned-in on-screen text stays the bare label, a drive with no measured date stays undated, and the exact-duplicate title refusal still runs afterwards. Phase BC now previews, hashes into the OST audit and checks that same dated title, so the title an operator confirms is the title that ships; an OST audit confirmed before this change for such a drive is stale for the new title and passes only through a route that judges the current text (`--ost-audit-confirmed` on the run, or a `.confirmed` marker stamped with the current audit hash; a system review does not re-confirm a stale day), which re-binds the stored hash; with none it refuses and names exactly those two routes. A split full_drive day is dated too: Phase BC now confirms the `— Part k of K` title Phase D ships (`Ireland (Sep 16, 2025) — Part 1 of 2`, one shared `ensure_unique_titles` call), where Phase D used to ship the bare label.
