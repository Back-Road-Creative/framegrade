## GPS quality filter (`gomoveshift/pipeline/gps_quality.py`)

- **Temporal teleport detector keys on km/SEC, not raw km** (`exceeds_physical_speed`, shared by chapters + label path): a seam must clear the spatial gate (`max(_TELEPORT_JUMP_FLOOR_KM=25, 20×median step)`) AND, when `dt` is known, exceed `_TELEPORT_SPEED_CEILING_KMH=1000`. A 25 km jump over a 10-min ferry dropout (~150 km/h) is preserved; 25 km over ~1 s (~90,000 km/h cold-start lock) is stripped. Unknown `dt` falls back to km-only.
- **Tuple-aware accessors** (`_point_lat`/`_point_lon`/`_point_time`): `filter_high_quality_points` reads lat/lon/time from positional `(t,lat,lon)` tuples, `GPSTrackpoint` (`lat`/`lon`) AND the GPX `Waypoint` model (`latitude`/`longitude` full-word attrs — otherwise read as None, silently disabling every gate on that shape), so null-island + spatial/temporal-teleport + sparse-sampling passes apply regardless of caller. HDOP/speed gates stay attribute-only and are inert on GPMF tuples (no such fields) — left live for any future source that supplies them.
- **Only locked fixes enter the canonical GPX** (`gopro_gps.extract_gopro_gpx`): the GPMF lock filter (`gpmd_filters.standard`) merely RELABELS a bad reading's `gpsfix` — it never drops the point — so `framemeta_to_gpx` is given `filter_fn=lambda e: e.gpsfix in GPS_FIXED_VALUES` to exclude NO/UNKNOWN-fix entries. Without it, a camera's pre-lock stale-cache coordinates (a real non-(0,0) position from a previous session, invisible to the null-island guard) leak into the GPX and pollute county voting / chapters / endpoints; GPX carries no fix channel, so no downstream consumer could re-classify them. The lock filter's `ReasonCounter` (the tally of relabels + why) is logged instead of discarded.
- **A recording with zero locked fixes writes no GPX at all.** `to_xml()` on an all-filtered result still yields a non-empty `<gpx>` skeleton with no trackpoints, so `extract_gopro_gpx` checks `gpx.get_points_no()` before writing: zero points removes any stale file at the target path and returns `None` instead of a path to an empty track. This keeps a GPS-less LF genuinely GPS-less downstream (`lf_has_gps=False`), routing it through the GPS-less skip path instead of the GPS-required chapter-density gate, which would hard-fail it.
