## OST package (regular_lf, `gomoveshift/pipeline/ost_applier.py`)

- Brand + location title visible t=0 through end of montage, crossfading out together over `ost_title_crossfade_sec`. Center brand is montage-only.
- Bottom-right logo watermark **disabled** for `regular_lf` (avoids double-logo with the YouTube channel watermark); `apply_ost(show_logo=True)` lives on for future opt-in layouts.
- Top-right persistent "gomoveshift.com" URL (full video); center-bottom end-card (last 6s).
- Missing logo → WARN + encode without watermark (does not silently drop).
- **Every OST write goes to a `.ost-partial` sibling and carries an explicit `-f`** (`_TEMP_OUTPUT_SUFFIX`, `_muxer_args`). ffmpeg never touches the final path, so a SIGKILL/OOM mid-encode can only strand bytes at a name no `*.mp4` glob adopts and no resume mistakes for a finished LF. But ffmpeg picks its muxer from the output EXTENSION, and that suffix is deliberately not a recognizable one — so the container the FINAL name implies has to be passed explicitly or ffmpeg aborts before writing a byte (`Unable to find a suitable output format … specify the format manually`, rc 234). The format is derived in one helper rather than hardcoded per call site, so a fourth encode added later inherits it instead of rediscovering the failure in production — otherwise the failure would surface only on the first LF burn, after a multi-hour master encode. Both burn commands and the missing-font stream-copy fallback go through it; the temp path stays the LAST argument, which `run_ffmpeg_encode`'s cleanup and the atomic tests both rely on.
- **Burned title word-wraps** (`_location_drawtext_filters`): PIL metrics pinned to the exact ffmpeg `FONT_PATH` (DejaVuSans-Bold, not the fallback chain), one centered `drawtext` per line, ≤`_LOCATION_MAX_LINES` (3). Garbage stays gated upstream by `validate_burned_ost_text` (`lf_title`, 100 chars).
- `apply_ost` **hard-fails** (`OST-EMPTY-LOCATION`) on an empty/whitespace location (an upstream cascade defect); missing-font stays a WARN + stream-copy. `montage_duration` clamps to `video_duration` for sub-montage LFs. `_escape_drawtext` delegates to the shared `ffmpeg_filters.escape_ffmpeg_text` (escapes `{`/`}`).
- **Pixel-width OST budgets** (`ost_validator.validate_ost`): beyond the codepoint cap, `text_fits_overlay` pixel-word-wraps via the render path's `wrap_text_for_ffmpeg` (font pinned to `FONT_PATH`) and rejects when wrapped text needs more than `max_lines` or any line exceeds the frame width. `_FORMAT_PIXEL_SPEC`: `lf`/`lf_title` fontsize-48 @ `1920×0.85` ≤3 lines; `shorts` fontsize-48 @ `1080−80` ≤2 lines.

### Optional map inset (`apply_ost(map_inset=MapInsetOverlay(clip_path, x, y))`)

- An RGBA clip (with alpha, its own size and fps, no longer than the input) is composited **after** the drawtext and the logo, inside the same ffmpeg command, so there is no second full-length transcode. `x`/`y` are the top-left corner in output pixels. `map_inset=None` (the default) leaves the argv byte-identical to before.
- **10-bit is kept by naming every format.** The graph is `[inset]format=yuva420p10le`, `[vbase]format=yuv420p10le`, `overlay=...:eof_action=pass:format=yuv420p10`, then `format=<encoder -pix_fmt>`. Leaving it to ffmpeg's auto-inserted conversion picks an 8-bit blend and costs a 10-bit master its gradients. 4:2:0 is used rather than 4:4:4 so the frame outside the inset takes no chroma up/down-sample round trip.
- `eof_action=pass`: once the inset clip ends the video carries on without it. `overlay` pairs each base frame with the inset frame current at its timestamp, which resamples the inset's fps to the output's.
- A missing clip file returns `None` and logs an error (no output written); the missing-font stream-copy fallback also refuses when an inset was requested, because a stream copy cannot composite it. Neither silently encodes without the inset.
- Tests: `tests/test_ost_map_inset_overlay.py` (argv identity when off, argv shape when on, a real-ffmpeg 10-bit gradient check).
