### Corrections-ledger place-name denylist

`validation/place_corrections.load_place_corrections()` closes the loop the comments triage report stops short of, reading a hand-curated YAML ledger at `GMS_CORRECTIONS_PATH` (default `<data home>/place_corrections.yaml`, where data home is `$GMS_DATA_HOME`, else `$XDG_DATA_HOME/gomoveshift`, else `~/.local/share/gomoveshift`): `corrections: [{wrong, correct}]` + `denylist: [name]`. Missing/empty/malformed -> empty `PlaceCorrections` (mapping `{}`, denylist `()`) -- a strict no-op until curated. `title_builder.build_lf_title` substitutes a mapped name or refuses (falls back to `per_lf_location`) a surviving denylisted one; `content_gates.check_metadata_quality` hard-fails shipped text still carrying a denylisted name as a belt-and-braces backstop.
