# Private night projects in the library

The Media library discovers up to 50 recent private night projects for the current
brand, including when no site or journey has been configured. Links open the existing
private project screen; no source filesystem paths, RAW/TIFF downloads, public URLs
or gallery registration are created. Gallery filters continue to apply only to gallery
entries. Disabling the Photos tab also removes this section.

The adapter opens the existing project database read-only and creates nothing on a
missing store. It rejects symlinked stores and malformed/cross-brand records, bounds
metadata reads, and reports unavailable records separately from an empty collection.
Schema-1 stack projects and schema-2 typed product projects share the section; each
row labels whether its progress counts stacks or products. Counts are recorded
processing results, not fresh quality/privacy approval. Preview
bytes remain checked by the existing authenticated project route before serving.

The linked project view can prepare a private still keeper through the established
people/face/plate/occupant blur checks and an EXIF-free JPEG export. Its receipt and
pixels remain private and unpublished; appearing here never makes a render a gallery
asset or authorizes scheduling. Video export and gallery registration remain separate.
